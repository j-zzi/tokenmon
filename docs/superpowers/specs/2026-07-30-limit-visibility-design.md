# 세션/주간 한도 가시성 개선 설계

## 목적

패널의 5시간·주간 한도 정보가 잘 읽히지 않는다. 두 가지 원인이 겹쳐 있다.

1. **대비 부족** — 리셋 시각을 그리는 `.duo .r`이 `--faint`(`#626269`) 10px다.
   duo 셀 배경(`#212124`) 위에서 명암비 **2.65:1**로, WCAG AA 본문 기준(4.5:1)에 한참 못 미친다.
2. **정보 부족** — "언제 초기화되는지"를 묻는데 절대 시각만 준다.
   5시간은 `3:45 리셋`(날짜 없음 → 오늘인지 내일인지 모름),
   주간은 `8/5 리셋`(시각 없음 → 그날 언제인지 모름). 남은 시간은 사용자가 직접 뺄셈해야 한다.

부수적으로 legend(`주간 62% / 5시간 47%`)가 바로 아래 duo와 같은 숫자를 중복 표시한다.

## 범위

`src/panel/` 안에서 끝난다. 사용량 수집(`src/usage/`), 메인 프로세스, 펫/말풍선은 건드리지 않는다.
`panelData()`가 이미 `{pct, resetsAt}`을 넘겨주므로 IPC 계약 변경도 없다.

## 1. 색 대비 — 4단계 위계

`--faint` 하나로 뭉뚱그리던 하위 정보를 두 티어로 나눈다.
명암비는 duo 셀 배경 `#212124`(카드 `#18181b` + `rgba(255,255,255,.04)`) 기준.

| 용도 | 현재 | 변경 후 | 명암비 |
|---|---|---|---|
| 값 `47%` | `--text` `#ececf0` | 유지 | 13.6:1 |
| 남은 시간 | — | **`--text-2` `#b4b4bc`** (신규) | **7.8:1** |
| 라벨 `5시간`, 절대 시각 | `--muted` `#8e8e96` | 유지 | 4.9:1 |
| 리셋 텍스트 | `--faint` `#626269` | duo에서 용도 폐지 | ~~2.65:1~~ |

`--faint`는 설정 섹션 힌트/`h2`/placeholder에도 쓰이는데 카드 배경 위에서 2.93:1로 역시 미달이다.
**`#626269` → `#82828b` (4.65:1)** 로 올려 AA를 넘긴다.

폰트 크기도 `10px` → 남은 시간 `11px` / 절대 시각 `10.5px`.

## 2. 리셋 표기 — 남은 시간 + 절대 시각 2줄

```
┌──────────────┬──────────────┐
│ ● 5시간       │ ● 주간         │   ← 라벨에 링 색 dot
│ 47%          │ 62%          │   ← 70/90% 넘으면 경고색
│ 2시간 41분 남음 │ 3일 남음       │   ← --text-2, 11px
│ 오후 3:45     │ 8/5(수) 오전 9:00│   ← --muted, 10.5px
└──────────────┴──────────────┘
```

패널 폭 340px → duo 셀 텍스트 영역 약 119px. 위 문구는 모두 여유 있게 들어간다.

### 포맷 규칙

`panel.js`의 `fmtTime`/`fmtDate`를 걷어내고 `src/panel/format.js`에 순수 함수 두 개를 둔다.
`panel.js`는 최상단에서 `require('electron')`을 하므로 그대로는 단위 테스트가 붙지 않는다.
포맷 로직만 분리하면 기존 `node:test` 스위트에 바로 편입된다.

```
fmtRemaining(resetsAt, now)
  d ≤ 0        → '곧 리셋'
  d < 1분      → '1분 미만'
  d < 1시간    → '41분 남음'
  d < 24시간   → '2시간 41분 남음'   (분이 0이면 '2시간 남음')
  그 외        → '2일 15시간 남음'   (시간이 0이면 '2일 남음')

fmtAbsolute(resetsAt, now)
  같은 날      → '오후 3:45'
  다음 날      → '내일 오전 9:00'
  그 외        → '8/5(수) 오전 9:00'
```

"같은 날 / 다음 날"은 경과 시간이 아니라 **자정 기준 달력 날짜 차이**로 판정한다
(`setHours(0,0,0,0)` 후 차이를 `Math.round`로 나눠 DST를 흡수).
23:50에 조회한 00:10 리셋이 "20분 남음 · 내일 오전 12:10"으로 나와야 하기 때문이다.

5시간·주간이 각각 다른 포맷을 쓰던 것(시각만 / 날짜만)을 **양쪽 다 같은 함수 쌍**으로 통일한다.
리셋 시점에 따라 날짜가 알아서 붙으므로 지표별 분기가 필요 없다.

`resetsAt`이 `null`이면 두 줄 모두 빈 문자열(현재 동작 유지).
`pct`가 숫자가 아니면 값은 `—`, 리셋 줄은 비운다(현재 동작 유지).

## 3. 30초 재계산

마지막 `panel-data`의 `{fh, wk}`를 모듈 스코프에 보관하고,
`setInterval(30_000)`으로 리셋 두 줄만 다시 그린다. IPC 왕복 없음.

패널은 blur 시 닫히지만 설정 섹션을 펼쳐두면 계속 떠 있고,
폴링 주기가 5분이라 그동안 "2시간 41분 남음"이 최대 5분까지 어긋난다.

## 4. legend 제거, 범례는 duo 라벨로 이동

`.legend` 블록(`panel.html:123-126`)과 이를 채우는 `panel.js:43-44`를 삭제한다.
다만 legend의 색 dot은 "바깥 링 = 주간, 안쪽 링 = 5시간"을 알려주는 유일한 단서이므로,
duo 라벨 앞으로 옮겨 그 기능은 유지한다.

dot 색은 링과 같은 규칙을 따른다 — 기본은 `var(--accent)`(주간) / `#7ec8ff`(5시간),
경고 구간에서는 링과 함께 앰버/레드로 바뀐다.

높이 수지: legend 삭제 −27px, 리셋 줄 추가 +14px → 패널이 약 13px 낮아진다.
`panel.js`의 ResizeObserver가 카드 실제 높이를 따라가므로 별도 처리는 없다.

## 5. 경고색을 `%` 값까지 확장

기존 `alertColor(pct)`(70% 앰버 / 90% 레드)는 링에만 칠했다.
같은 색을 `.v`(`47%`)와 라벨 dot에도 적용한다.
`setRing`과 동일하게 `style.color = alertColor(pct) || ''` 패턴을 써서,
경고 구간을 벗어나면 CSS 기본색으로 되돌아가게 한다.
